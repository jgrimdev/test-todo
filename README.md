# 📝 CLI To-Do App (Python 2026)

Jednoduchá, ale robustní konzolová aplikace pro správu úkolů. Projekt demonstruje použití moderních Python standardů, OOP a automatizovaného testování.

## 🚀 Funkce
- **CRUD operace:** Přidávání, zobrazování a plnění úkolů.
- **Persistence:** Data jsou automaticky ukládána do JSON souboru.
- **Bezpečnost:** Validace vstupů a ošetření chyb (Error Handling).
- **Type Hinting:** Plně typovaný kód pro lepší čitelnost a stabilitu.

## 🛠 Technologie
- Python 3.9+
- Pytest (Automated Testing)
- Dataclasses & Type Hints
